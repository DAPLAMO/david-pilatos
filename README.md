**Tienda web responsive con catálogo para hombre y mujer, novedades, ofertas y formulario de pedidos.**

## Qué incluye

- **Inicio** con carrusel de promociones y categorías destacadas
- **Catálogos** de hombre y mujer con tarjetas de producto
- **Novedades** y **ofertas** en secciones propias
- **Pedidos:** formulario para solicitar productos
- Diseño **responsive** pensado primero para el celular

## Estructura

```
├── index.html     # Inicio
├── hombre/        # Catálogo de hombre
├── mujer/         # Catálogo de mujer
├── nuevo/         # Novedades
├── sale/          # Ofertas
├── pedidos/       # Formulario de pedidos
├── CSS/ · IMG/    # Estilos e imágenes
└── bootstrap-5.3.3-dist/
```

## Cómo verlo

Clona el repositorio y abre `index.html` en el navegador. No necesita servidor.

```bash
git clone https://github.com/DAPLAMO/david-pilatos.git
```

## Lo que practiqué

Maquetación con el sistema de rejilla de Bootstrap, componentes (carrusel, navbar, cards, formularios), organización de un sitio de varias páginas y control de versiones con Git.
